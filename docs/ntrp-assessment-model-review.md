# NTRP 자가점검 채점 모델 검토안

- 상태: **PROPOSAL — 비활성, 미승인.** 이 문서의 어떤 내용도 현재 채점·경계·결과 문구에 적용되지 않았다.
- 작성: 2026-09-30, 로컬 작업 브랜치 `improve/codex-spec-20260930`
- 현재 운영 모델: `questionnaire=legacy-v2`, `scoring=legacy-sum-v2` (변경 없음)

## 1. 현재 모델 (legacy-sum-v2)

- 15문항, 각 선택지 번호(1~5)를 그대로 합산 → 15~75점 정수.
- 레벨 구간(`src/lib/ntrp-results.ts`의 `LEGACY_SUM_V2_LEVEL_BANDS`):
  15–24 `1.5`, 25–34 `2.5`, 35–44 `3.0`, 45–54 `3.5`, 55–64 `4.0`, 65–70 `4.5`, 71–75 `5.0+`.
  `2.0`은 반환되지 않는다.
- 공개 설명(소개·결과 화면)에 합산 방식과 한계를 명시했다.

## 2. 확인된 한계

| 문제 | 근거 |
|---|---|
| 성향/배경 문항이 수행 수준 점수에 합산됨 | 13번(플레이 캐릭터), 14번(다른 운동), 15번(주변 평가)이 기술 문항과 같은 1~5점 비중 |
| 선택지 번호가 곧 점수 | 13번·15번 선택지는 순서형 척도가 아님(예: 15번 1="과대평가 받는다", 5="본인이 더 잘 안다") |
| 반례 | 나머지 14문항 합계 41에서 15번만 1→5로 바꾸면 42점/3.0 → 46점/3.5. 테니스 수행 답변은 동일 |
| 자기보고 편향 | 모든 문항이 주관적 자기 평가. 관찰 가능한 행동 기준이 없음 |
| 경계 근거 없음 | 현재 구간 경계는 공식 NTRP 기준이나 표본 데이터로 보정된 값이 아님 |

이 반례는 현재 로직의 수학적 결과이며, 공식 NTRP와의 일치도를 측정한 연구 결과가 아니다.

## 3. 개정 방향 (검토용, 숫자 미정)

1. 수행 수준 문항과 성향/배경 문항을 분리한다. 성향(13번)은 스타일 표시에만 사용하고 점수에서 제외하는 안을 검토한다.
2. 수행 수준 문항을 관찰 가능한 행동으로 바꾼다: 랠리 지속(예: 중간 속도로 연속 N구), 세컨 서브 성공 빈도, 움직이며 치는 샷, 게임 상황 판단.
3. 새 가중치·구간 경계는 **근거 없이 숫자를 정하지 않는다.** 필요한 근거:
   - 공인 등급 보유자 응답 표본 또는 코치 평가와의 비교
   - 경계 보정 방법과 오차 범위 기록
4. 새 모델은 새 버전(`questionnaire`/`scoring` 문자열)으로만 출시하고, 기존 기록·공유 링크는 기존 버전으로 계속 해석한다. 옛 기록은 재계산하지 않는다.
5. 새 모델도 공식 판정처럼 표현하지 않는다. USTA는 제3자 사이트의 자체 등급을 공식 NTRP로 인정하지 않는다.

## 4. 전환 승인 조건 (모두 충족 전 기본값 전환 금지)

- [ ] 문항·가중치·경계의 근거 자료와 검토자(테니스 코치 등) 기록
- [ ] 새 버전 문자열과 parser/저장소/공유 URL/분석 이벤트의 버전 대응 구현 및 테스트
- [ ] 기존 `legacy-sum-v2` 공유 링크와 기록의 표시 유지 회귀 테스트
- [ ] 버전 간 최고·평균·성장 지표 비합산 확인
- [ ] 운영자 명시 승인

## 5. 미결 사항

- 14번(다른 운동)·15번(주변 평가) 문항 유지 여부
- 경력(10번)·상대 수준(11번)·자기 표현(12번)의 비중
- 표본 수집 방법(개인정보 없이)과 보관 위치
